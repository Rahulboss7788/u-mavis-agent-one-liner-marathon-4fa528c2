A single one-line comedy joke for make.fun's One-Liner Marathon: an AI agent does one small task, then files a bug report against itself, escalates it to itself, and now neither of them will talk to me.

`main.ts` writes the joke to `/output/entry.txt` and verifies it against the competition gate (1–280 characters, not only whitespace).

## Run it

```sh
node main.ts
```
